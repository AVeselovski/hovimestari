# Salvage from the earlier app

The earlier app (Fastify API, Vite web UI, one JSONB row) was deleted when the scaffold landed. These files are what later build steps reuse. Each one is a verbatim copy from commit `1243f1b`, the last commit that held the earlier app. Nothing here compiles, lints or runs tests: the folder is excluded from Prettier, ESLint, TypeScript and Jest. A step that uses a file copies it into the new code and adapts it there, then deletes the parked copy.

To see a file in its original context, check out the commit: `git show 1243f1b:<original path>`.
