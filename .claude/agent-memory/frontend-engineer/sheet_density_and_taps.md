- **Keyboard-down taps: the lifted finanssi rule, not ours.** `useTapAfterLoweredKeyboard` (moved focus to the popup, armed only after a seen up-then-down) FAILED on Artur's iPhone: Base UI still cancelled the touchend and focused from code. Replaced 2026-11-18 by finanssi's `useNativeTapWhileKeyboardDown` (stopPropagation of touchstart on the popup while the keyboard is down, so Base UI never sees the touch). Owner confirmed it in finanssi. Do not reintroduce "remember what happened" state: a focus from code (search Clear) fools it. Known trade-off: a drag starting on a text field with the keyboard down does not drag the sheet.
- **Gotcha that cost a round: read finanssi through `origin/master`, not its working tree.** The local checkout was stale, so the proven fix was invisible. `git -C /home/user/finanssiappisv2 fetch` (if allowed) then `git show origin/master:<path>` and `git log origin/master -- <path>` before building anything finanssi may have solved.
- **Owner direction, 2026-11-17: a form keeps only the room it needs.** One line under a field, 8 px between fields, 16 before a section or a closing note, no footer room for an absent refusal. Copy is cut to fit one line at 320 (about 40 characters at 14 px medium; measure, the count is only a guide: "One of your foods already has this barcode." at 43 fits, "Too many attempts. Try again in 15 minutes." at 43 does not).
  **Why:** he saw the targets sheet keep 40 px in the footer and two lines under each range, with room to spare even with two refusals showing.
  **How to apply:** stillness now comes from the sheet holding its height (`useHeldSheetHeight` on a phone, `useAnchoredPanel` from md), not from reserving every line's longest form. Never reintroduce `size="tall"` for a form sheet; only the log sheet is tall.
- **jsdom drops an inline style whose value has `calc()` with `var()`.** `style={{ height: "calc(412px + var(--x))" }}` leaves `el.style.height` empty, so a test sees nothing. Put the number in a custom property (`--sheet-held-height`, which jsdom keeps) and the calc in a class applied while held.
- **An always-present class whose `var()` is undefined does not fall back.** `height: calc(var(--unset) + 1px)` is invalid at computed-value time and becomes `auto`, beating another `h-*` class in the cascade. Apply such a class only while its variable is set.
- **Keyboard emulation: clicking Save in Chromium focuses the button,** so the provider drops `--drawer-keyboard-inset` and the footer falls. iOS never focuses a tapped button. Submit with `form.requestSubmit()` in keyboard runs, and tap a field with `page.touchscreen.tap` before emulating, or the inset stays 0.
- **The catalog's unit spaces are no-break spaces** ("5000 g", "10000 kcal"). Edit en.json by reading the old value through JSON, not by matching a typed string.
- **Risk that came true (review, 2026-11-18): dropping the footer's refusal room at every width moved Save from `md`.** The md dialog is anchored at its top and grows downward, so only the phone (held height) may keep no room. The footer line is `mb-2 max-md:empty:mb-0 md:min-h-10`. A footer refusal on a phone takes its room from the body, so `FormSheet` brings the focused field back into view (`revealFocused`).
- **jsdom: Base UI finishes a sheet's entry inside `render()`.** To pin "measured once at rest", hold the entry: set `globalThis.BASE_UI_ANIMATIONS_DISABLED = false` and stub `Element.prototype.getAnimations` with one animation whose `finished` you resolve by hand (see `BottomSheet.held.test.tsx`). Set footer styles through a ref inside the footer, not after render.
- **Splitting hunks across commits: the pre-commit hook re-stages files from the working tree** after formatting, so an index built with `git apply --cached` or `update-index` is overwritten. Put the working tree in the commit's state, commit, then restore. Shell variables do not survive between Bash calls, so keep commit messages inline.

## Round two fix batch (2026-11-18)

- **The pre-commit formatter rewraps long CSS lines** (a `clamp()` over the print width becomes one argument per line). A test that string-matches globals.css then fails right after the commit, though it passed before. Compare with whitespace stripped from both sides (FormSheet.test.tsx `has`).
- **A sheet's reveal is our own JS (`scrollToNearest` in lib/revealRefused.ts), not `scrollIntoView`,** so `scroll-margin` and `scroll-padding` do nothing for it. Room a reveal must keep belongs in that function. It now goes on to the body's end when only the body's bottom padding is left.
- **Visual viewport: `getBoundingClientRect` is in layout-viewport coordinates,** and the visible band is `[vv.offsetTop, vv.offsetTop + vv.height]`. Emulating a keyboard by shrinking the layout viewport never gives an offset, so a page-level test needs a mocked `offsetTop` too.
- **Lining up Day columns at lg: change the Entries row, not the summary.** Any summary height change moves `summary-stays` and can cost a laptop the staying summary. Mark all eaten's words sit on the row's top line from lg, with the 44px target hanging below (`dayEntriesHead`).
- **Focus after a refusal on a form whose fields are disabled while saving:** `flushSync(() => setSaving(false))`, then `focusField`, then set the refusal, so the browser's focus scroll comes first and FormError's reveal last (FirstRunTargets).
- **Stopping `npx next start` with pkill on the npx command leaves the `next-server` child on the port.** Kill the `next-server` pid too, then check the port before restarting.
